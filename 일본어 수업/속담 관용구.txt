井の中の蛙は大海を知らず 
(いのなかのかわずはたいかいをしらず）
→ 우물안 개구리
※ 일반적으로 蛙 는 かえる라고 읽으나 여기선 かわず

馬の耳に念仏
(うまのみみにねんぶつ）
→ 말 귀에 염불. 우리나라 속담에 소귀에 경읽기
즉 말해도 효과가 없는 것

猿も木から落ちる
(さるもきからおちる）
→ 원숭이도 나무에 떨어진다.

猫に小判
(ねこにこばん)
→小判 은 옛날에 쓰던 금화. 대상에따라서 가치가 있는것도 가치가 없어지는걸 의미

泣き面に蜂
(なきつらにはち)
→ 우는 얼굴에 벌, 불행한 일이 곂치는 상황

月とすっぽん
（つきとすっぽん）
→ 달과 자라 , 그만큼의 비교불가한 차이가 큰것

虎穴に入らずんば虎子を得ず
（こけつにいらずんばこじをえず）
→ 호랑이 굴에 들어가지않으면 호랑이 새끼를 잡을 수 없다. ( 하이 리턴을 위해서는 하이 리스크를 감수해야 함)

能もある鷹は爪を隠す
（のうもあるたかはつめをかくす）
→ 능력있는 매는 발톱을 숨긴다, 즉 능력있을 수록 오히려 겸손하다는 뜻

海老で鯛を釣る
(えびでたいをつる）
→ 새우로 도미를 낚다 즉 작은것으로 큰 것을 얻다

逃した魚は大きい
（のがしたさかなはおおきい）
→ 놓친 생선은 크다 ( 내가 얻지 못하게 된건 가치가 크게 느껴진다는 의미)

一難去ってまた一難（いちなんさってまたいちなん) : 한 재난이가고 또 다른 재난, 즉 좋지 않은일이 연달아 발생하는 것.

二兎を追う者は一兎をも得ず（にとをおうものはいっともえず）：두마리 토끼를 잡으려는 자는 한마리 토끼도 얻지 못한다. ( 즉 너무 욕심부리면 하나도 제대로 못건진 다 . )

三度目の正直　（さんどめはしょうじき）: 세번째는 정직. 즉 세번째는 진짜 ( 처음에 몇번은 잘 안되거나 실패했으나, 이번 만큼은 잘 될거라는걸 다짐할 때 쓰면 됨)

人の噂も七十五日（ひとのうわさもしちじゅうごにち）: 사람의 소문도 75일, 즉 소문은 금세 잊혀진다.

二階から目薬（にかいからめぐすり): 이층에서부터 안약, 즉 맘대로 안되거나, 효과가 없는 것 (もどかしい (답답) 한 상황에 쓰는 말 )

仏の顔も三度（ほとけのかおもさんど）부처 얼굴도 세번. 즉 아무리 상냥한 사람도 세번 (자주 반복되면) 화를 낸다.  (참는데도 한계가 있다는 뜻 ) 

二度あることは三度ある（にどあることはさんどある) : 두번 있는 일은, 세번 있는다. 즉 반복된건 또 반복되므로 주의 해야 함.

早起きは三文の徳（はやおきはさんもんのとく): 三文은 예전 화폐단위 (옛 동전 세개, 큰돈은 아님) 즉 일찍일어나는건 쏠쏠한 이득이 된다는 의미

天は二物を与えず（てんはにぶつをあたえず）:하늘은 두개 물건을 전해주지 않는다. 즉 사람에게는 모든 재능을 다 주지는 않는다.

一を聞いて十を知る（いちをきいてもじゅうをしる）: 하나를 들으면 열을 안다. (우리랑 똑같음)

一寸の虫にも五分の魂 ( いっすんのむしにもごぶんたましい) : 한 촌의 벌레에도 5분의 영혼 (이 있다.) 여기서 五分 은 0.5寸 에 해당하는 길이 단위. 
즉 아무리 작은 미물이라도 무시할수없는 영혼, 의지가 있다라는 뜻. ( 지렁이도 밟으면 꿈틀한다. )
